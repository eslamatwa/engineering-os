# Claude Desktop integration

Claude Desktop is a secondary interface, not a separate operating model. An MCP server should expose narrow, auditable tools over the same workspace and orchestration contracts:

- read project brief and state;
- create or inspect task records;
- request a plan;
- retrieve validated evidence and ledger summaries;
- request human approval where required.

Tools that mutate workspace state must enforce the same execution mode and policy checks as Claude Code.
